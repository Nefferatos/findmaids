# Data Map

Inventory prepared 2026-10-23. Retention values are operational defaults, not a legal determination. Confirm purposes, lawful basis, notices, processors, cross-border transfers, and retention with Philippine counsel/DPO before production.

| Data                                                                                         | Source / purpose                                                   | Storage                                                                                                    | Access                                                                                           | Retention / deletion                                                                                                                                                       |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Account identity (name, email, role, password hash, verification/reset tokens, TOTP secrets) | Registration, authentication, account security                     | Supabase Postgres (`User`, token tables); passwords bcrypt-hashed; TOTP secret encrypted                   | Account owner for profile; ADMIN scoped operations; authentication service                       | Account life plus legal/security need. Reset/verification tokens have expiry and single-use markers. Account deletion currently requires operator handling; not automated. |
| Agency listing (contact, address, license, services, media)                                  | Agency onboarding and public directory                             | Postgres; public media in `findmaids-media`; payment/license evidence in private storage                   | Agency owner for own agency; ADMIN/authorized STAFF workflow; approved public listing fields     | Listing life and dispute/legal needs. Public files must be removed when no longer needed under approved schedule.                                                          |
| Enquiries (name, email, phone, message, date/budget, consent)                                | Public form or chat; route a requested response                    | Postgres `Enquiry`; consent timestamp and draft policy version; IP hash only                               | Selected agency owner, authorized admins/staff; user can request export                          | Current cron anonymizes after 365 days by default (`DATA_RETENTION_DAYS` applies to AI logs/cookie records). Confirm retention and invoice/legal holds with counsel.       |
| Reviews and reports                                                                          | User-submitted reviews and abuse reports                           | Postgres                                                                                                   | Public only after moderation; agency sees published review; moderation roles see pending records | Keep per approved dispute/content policy. No automated purge currently specified.                                                                                          |
| Conversations/messages/handoffs                                                              | Web chat and inbound channels                                      | Postgres; signed visitor continuation token is hashed; IP hashed; masked content                           | Visitor holding signed cookie; relevant agency/admin staff per workflow                          | Conversation expiry is 365 days; subscription cron purges expired conversations and cascades messages, feedback, handoffs.                                                 |
| AI usage and feedback                                                                        | Safety, budget, product quality                                    | Postgres `AiCallLog`, `AiFeedback`; call wrappers mask prompts; token/cost metadata                        | ADMIN AI control; agency-scoped summaries where exposed                                          | AI call logs default to configurable 365 days; feedback is retained with message until message deletion. Verify masking and access in staging.                             |
| Cookie preferences                                                                           | Analytics opt-in/out and policy version record                     | Hashed anonymous key plus optional user ID in `CookieConsent`; HttpOnly consent cookie contains random key | Service; subject can change via browser preference control when exposed                          | Configured retention default; cron deletes after `DATA_RETENTION_DAYS`.                                                                                                    |
| Analytics events                                                                             | Profile views, contact clicks, sponsored impression/click counting | Postgres; analytics collector only runs after analytics consent                                            | Aggregate agency owner and admins                                                                | No current purge policy; define period before production.                                                                                                                  |
| Payments and invoices                                                                        | Subscription, reconciliation, refunds, tax/invoice records         | Postgres; private invoice/proof objects in Supabase private bucket                                         | Owning agency for invoices; ADMIN/finance roles for reconciliation/proofs                        | Retain for statutory accounting/tax and dispute period as determined by counsel/accountant; do not purge with general user deletion.                                       |
| Audit/security events and rate limits                                                        | Accountability, throttling, incident response                      | Postgres (`AuditLog`, `RateLimitBucket`)                                                                   | ADMIN; rate limit service                                                                        | Expired rate buckets are deleted by cron. Define audit log retention and legal hold policy.                                                                                |
